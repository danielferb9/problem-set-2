## Descripción

Este repositorio contiene el código y los datos del Problem Set 2 del curso. El análisis se realiza en R e incluye la importación, limpieza y procesamiento de datos del módulo de identificación y sitio o ubicación de la encuesta DANE.

## Cómo ejecutar el código

1. Abrir el proyecto `problem-set-2.Rproj` en RStudio.
2. Ejecutar el script `code/code.r`.

## ¿Cómo eliminar repositorios en los que colaboro?

Si eres colaborador (no propietario) de un repositorio en GitHub y deseas dejar de aparecer en él, **no puedes eliminarlo** ya que no te pertenece. Sin embargo, puedes **abandonar el repositorio** siguiendo estos pasos:

1. Ir a **GitHub.com** e iniciar sesión en tu cuenta.
2. Navegar al repositorio del que deseas salir.
3. Hacer clic en la pestaña **"Settings"** (Configuración) del repositorio.
4. En el panel izquierdo, desplazarse hacia abajo hasta la sección **"Danger Zone"**.
5. Hacer clic en **"Leave this repository"** (Abandonar este repositorio).
6. Confirmar la acción.

> **Nota:** Solo el propietario del repositorio puede eliminarlo completamente. Como colaborador, únicamente puedes abandonarlo para que desaparezca de la lista de repositorios en los que participas.

Si eres el **propietario** del repositorio y deseas eliminarlo:

1. Ir a la página del repositorio en GitHub.
2. Hacer clic en **"Settings"**.
3. Desplazarse hasta la **"Danger Zone"**.
4. Hacer clic en **"Delete this repository"**.
5. Escribir el nombre del repositorio para confirmar y hacer clic en **"I understand the consequences, delete this repository"**.
